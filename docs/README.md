# 观澜 Guanlan · 产品介绍

> 司辰记时，观澜见脉。档案在本地，每次改动与拍板都有迹可循。

观澜是一款**本地优先、零锁定**的文件工作台。它为任意目录建立可追溯的时间线与版本快照，用星图关系与证据锚点串起「为什么变成现在这样」，并内置全格式阅读器与面向智能体的 MCP 上下文基座。

所有索引、快照与阅读状态都保存在本机私有数据目录。观澜不会自行写入或移动你的业务文件，也不依赖云端服务。

---

## 它解决什么问题

- **资料越积越多，来历说不清。** 一个目录里有几百上千份文档、图纸与 PDF，想找「这个结论是怎么来的」「这张图什么时候改过」，只能靠回忆和文件名。
- **决定散落在各处。** 结论写在文档里，依据在另一份材料里，后续调整又在会议纪要里；时间一长，没人能完整复述当时的取舍。
- **与智能体协作要反复搬上下文。** 每次让智能体接手，都要手工挑文件、贴正文、交代背景，既慢又容易漏掉关键依据。

观澜把这三件事放回同一条时间线上：资料有版本，版本有事件，决定有证据，上下文可复用。

---

## 核心能力

### 一眼看懂项目的时间与关系

同一份工作区可以按**时间线、日历、星图、资产库**四种视图浏览：事件按发生时间排列，活跃密度按日聚合，引用与版本关系铺成可缩放的星图。任何节点都能直接打开当时的资料版本，并保留返回路径。

### 全格式版本时光机

去重快照 + SHA-256 内容哈希，记录每一次内容变化。支持 Markdown、SVG、CSV/TSV、XLSX 工作簿与全部 UTF-8 源码/纯文本的版本演化轴、按格式分派的差异对比，以及「续读保持旧版」。改名与移动不会切断版本链；A → B → A 的恢复同样可追溯。

### 全格式阅读器

Markdown、Office（DOCX / XLSX / PPTX）、PDF、SVG、图片、纯文本与代码，以及**无同源权限的 HTML 隔离沙盒**（离线 CSP，可按需放行 HTTPS 外链）。阅读器共享搜索、版本切换、阅读位置与引用跳转。

### 决定与证据锚定

把决定、证据指针、来源版本与文档章节绑定，形成可复核的因果链。拍板可以**就地回写**到源文件的卡点块，写入前做乐观并发校验：磁盘内容与阅读时不一致时**冲突不覆盖**，内容存成草案等你处理。

### 智能体上下文与 MCP

通过 stdio 向支持 MCP 的智能体暴露受限的本地工具：读取已索引版本、提交修订草案、登记拍板、提交检查点、组装 Token 预算感知的上下文包、检索工作区。代理**不直接读工作区文件**，只按已索引的版本读；路径先过沙箱，敏感凭据路径一律拒绝。

### 检索

标题、路径、正文与决定编号混合检索。中文按双字切分并在原文行内回验，编号走精确通道；索引未就绪时如实返回空结果，不拿半成品冒充结果。

### 多项目与参考工作区

可以在多个工作区之间切换；其他已索引的工作区可以**只读挂载**，跨项目检索历史规范、架构图与决定依据。参考区零写入，离线时保留最后已知摘要并明确标记。

### 阅读状态与个人记忆

已读 / 未读、收藏、批注与阅读位置按版本记录。目录树递归汇总未读，支持单篇或整目录一键标已读；读后有更新会以双环提示，切回应用仍能接着读。

## 它刻意不做什么

- **不擅自写你的业务文件。** 只有你在界面上显式触发、或智能体经授权触发的少数操作会写入，且都带人工确认、乐观并发与路径校验。
- **删除只进系统回收站**，不做永久删除，也不提供永久删除接口。
- **不拿当前内容冒充旧版本。** 快照不可读就明说，不伪造历史。
- **不生成第二套历史。** 所有入口指向同一份资料身份。
- **无遥测、无云同步。** 外部网络只在沙盒页面显式放行外链或手动检查更新时出现。
- **不锁定格式。** 原始文件保持可访问，索引与快照只是旁路记录。

## 适合谁

- 接手一个陌生项目，需要在短时间内看懂来龙去脉的人。
- 长期维护一套方案、图纸或规范，需要随时回答「当时为什么这样定」的人。
- 与智能体协作开发，希望上下文准确、可追溯、可复用的人。
- 需要核对决定链与交付依据的团队。

## 安装（Windows）

前往 [GitHub Releases](https://github.com/locooooooooo/guanlan/releases) 下载最新版本：

- `Guanlan_<版本>_x64-setup.exe`：NSIS 安装包，安装后注册资源管理器「用观澜打开此文件夹」右键菜单（推荐）。
- `Guanlan_<版本>_x64_zh-CN.msi`：MSI 安装包，适合企业分发。
- `guanlan-cli-<版本>-x86_64-pc-windows-msvc.exe`：独立命令行与 MCP 代理，改名为 `guanlan.exe` 并加入 `PATH` 后可用。
- `SHA256SUMS`：上述二进制的校验和清单。

> 安装包目前没有代码签名，首次运行可能出现 Windows「未知发布者」提示。Windows 10/11 需已安装 WebView2（系统通常已内置，缺失时安装器会引导安装）。

## 本地数据

- 索引与去重快照默认写入 `%LOCALAPPDATA%\Guanlan\workspaces\<rootKey>`，可用 `GUANLAN_DATA_DIR` 整体覆盖。
- 卸载应用不会删除工作区原始文件。
- 业务目录、索引库与快照彼此独立：迁移工作区只需要把原目录带到新位置重新索引。

| 层 | 技术 | 职责 |
| --- | --- | --- |
| Web 前端 | React 19 · Vite 8 · Tailwind CSS 4 · d3 | 时间线、星图、阅读器、资产库与全部交互 |
| 领域核心 | Rust · `guanlan-core` | 领域规则、SQLite 索引、去重存储、只读查询契约 |
| 读服务 | Rust · axum · rusqlite (bundled) | `/api/v1` HTTP + SSE、`guanlan` CLI、MCP stdio |
| 桌面壳 | Tauri v2 | 进程内嵌服务、窗口与安装包 |
